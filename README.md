# Newsletter Frontend

Hier erstelle ich das Frontend für das Projekt Newsletter. Hier soll man sich
registrieren können für E-Mailbenachrichtigungen, die durch meine Veröffentlichungen 
auf GitHub ausgelöst werden und über diese informieren. 

## Ziele

- erstellen einer Fullstackanwendung
- getrennte Entwicklung von Front- und Backend
- Deployment auf Azure
- Integration in meine Portfoliowebsite
- Demonstration eines real funktionierenden Mailverteilersystems
